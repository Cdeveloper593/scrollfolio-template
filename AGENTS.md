# ScrollFolio template — working notes
- Next.js 16 (App Router, React 19, TS strict), Tailwind v4. Commands: `npm run dev`, `npm run check`.
- Content: `src/config/site.config.ts` + `src/components/sites/portfolio/content.json`. See TEMPLATE-GUIDE.md.
- Do not restructure the `.st` / `.el` sections in the homepage markup without updating `scene.ts` — the scroll engine measures them.
